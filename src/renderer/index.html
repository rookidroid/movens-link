Movens Link
MOVENSLink · 5-axis arm controller

Movens Link starts in simulation: every feature drives a virtual arm in the 3D view, so positions and sequences can be prepared without the robot. Connect to switch to the real arm; disconnecting stops the arm and returns to simulation.

Connecting over WiFi
  • The arm runs its own WiFi access point. Join the network movens (password movens_1234, unless changed in movens_config.h) from this computer.
  • The robot then answers at 192.168.4.1. Use localhost:8080 for the stand-alone mock robot (npm run mock).
  • The simulated arm uses its own calibration; taught positions in degrees work on the real arm once its joints are calibrated to the same conventions.
  • Joint-space positions and sequence speeds need firmware with the /movejoints endpoint (the movens repository's current movens firmware).
